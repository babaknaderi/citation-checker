# Support

Use GitHub Issues for reproducible bugs, compatibility problems, and focused feature requests. Before opening an issue, search existing issues and test with the latest plugin release.

Include the host and version (GitHub Copilot CLI or Claude Code), operating system, plugin version, minimal LaTeX/BibTeX input when shareable, expected behavior, actual behavior, and relevant non-sensitive logs. Remove credentials, private manuscript content, and unpublished research before posting.

This community project provides support on a best-effort basis and has no guaranteed response time.
